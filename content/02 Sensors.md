# Sensors

A sensor measures a value, such as temperature, and sends it to a [[01 Gateway]].

## Configuration

| Setting  | Default | Note                  |
| -------- | ------- | --------------------- |
| interval | 60      | seconds between readings |
| alerts   | true    | see [[04 Support hours]] |

> [!warning] Battery
> Replace the battery when the dashboard shows less than 10 %.
